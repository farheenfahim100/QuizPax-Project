Help & User Guide

This page provides guidance on how to use QuizPax for both teachers and students. QuizPax is designed to be simple to use, but the sections below explain the main features and workflows.

For Teachers

Creating an Account

Teachers can register for an account using the registration page. Once logged in, teachers are taken to the dashboard where they can manage folders, question sets, and start live games.


Creating Question Sets

Folders store Q&A sets, and these themselves store questions. This structure allows you to keep your sets ordered and organised. Each question consists of one correct answer and three incorrect answers. These sets can be used later to host live games.


Hosting a Game

After selecting a question set, teachers can create a game by choosing a question set and a game mode. A unique game PIN is generated, which students use to join the lobby.

While in the lobby, teachers can see which students have joined and can start the game when ready. In team-based modes, teachers are prompted to select the number of teams before starting the game.


During the Game

Teachers can monitor student progress in real time via the data dashboard. A leaderboard shows students' scores and relative positions. Alerts may appear when many students answer a question incorrectly, allowing teachers to identify areas of confusion. Alerts will automatically disappear once the accuracy rate of that question reaches above the pre-defined 40% threshold. Additionally, students can flag questions and these will appear on the teacher's in-game dashboard. Teachers can remove questions from the flagged area once the issues are resolved.


For Students

Joining a Game

Students do not need to create a game. They simply login and enter the game PIN provided by the teacher to join the lobby. Whilst in the lobby, students must wait for the teacher to start the game.


Answering Questions

Once the game starts, questions appear one at a time and in a random order for each student. Students select the answer they believe is correct. Immediate feedback is provided after each submission to ensure that students can constantly improve.


Flagging Questions

If a question is confusing, students can flag it using the flag button. This notifies the teacher that clarification may be needed. Students can flag questions again if they encounter them later.


Need More Help?

If you encounter issues, ensure you are using a modern browser and have a stable internet connection. QuizPax is designed for live classroom use.
